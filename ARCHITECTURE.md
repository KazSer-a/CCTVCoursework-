# Архитектура CCTVCoursework

Пути к исходникам указаны относительно `CCTVcwg/`. Документ описывает назначение файлов и типы, которые будут в них реализованы.

## Сборка и запуск

| Файл | Содержимое |
|---|---|
| `CMakeLists.txt` | Цель приложения `CCTVNSTU`, список исходников и форм Qt, зависимости и цели тестов. Сборка на Windows и Linux. |
| `.gitignore` | Исключения для каталога сборки и локальных настроек Qt Creator. |
| `src/main.cpp` | Функция `main` создаёт `QApplication`, подготавливает службы, запускает вход и открывает главное окно. |

## Модель

| Файл | Структуры и классы |
|---|---|
| `src/model/PlanObjects.h` | `PlanPoint` хранит координаты X и Y в метрах. `PlanSegment` задаёт отрезок двумя точками. `BuildingFootprint` хранит внешний контур и внутренние контуры дворов. `Building` хранит один или несколько таких полигонов и высоту. `Fence` хранит начало, конец и высоту участка ограждения. `Road` хранит ломаную дороги. |
| `src/model/PlanObjects.h` | `ObservationPoint` хранит положение и высоту цели. `ObservationLine` хранит линию наблюдения, высоту цели и шаг контрольных точек. `ObservationTarget` объединяет ID, подпись и геометрию одного из этих двух типов. Ворота, двери и КПП задаются подписанными целями. |
| `src/model/PlanObjects.h` | `MountZone` хранит ID, точку или отрезок, допустимые высоты и шаг размещения вдоль отрезка. Для монтажа на фасаде хранит ссылку на здание и выбранный отрезок стены. `MapReference` хранит географическую привязку импортированного плана. |
| `src/model/CameraTypes.h` | `CameraModel` хранит ID, название, цену в целых денежных единицах минимального номинала, дальность и горизонтальный и вертикальный углы обзора. `CameraPose` хранит положение, высоту, азимут и наклон. `CameraPlacement` хранит параметры установки и копию характеристик выбранной модели на момент расчёта. |
| `src/model/CameraTypes.h` | `CoverageSample` хранит ID цели, координаты и высоту контрольной точки. `OptimizationResult` хранит статус подбора, список установок, общую цену и результаты покрытия контрольных точек. |
| `src/model/Project.h` | Класс `Project` хранит коллекции объектов плана, настройки географической привязки и последний результат подбора. Предоставляет операции добавления, редактирования и удаления объектов. |
| `src/model/Project.cpp` | Проверяет координаты, контуры, высоты, шаги, уникальность ID и ссылки между объектами. Для полигона здания проверяет, что внутренние контуры находятся внутри внешнего и не пересекают друг друга или внешний контур. Применяет изменения после проверки и помечает расчёт устаревшим при изменении его исходных данных. |

## Интерфейс

| Файл | Содержимое |
|---|---|
| `src/ui/mainwindow.h` | Класс `MainWindow` хранит текущий `Project`, состояние пользовательской сессии и ссылки на элементы главного окна. |
| `src/ui/mainwindow.cpp` | Связывает редактор, панель свойств, каталог и команды открытия, сохранения, импорта и расчёта. Команда «Файл → Импорт GeoJSON…» открывает диалог выбора локального файла. При ошибке импорта текущий план остаётся доступен. Запускает длительные операции в фоне, передаёт им сигнал отмены и применяет результат к соответствующей версии проекта. |
| `src/ui/mainwindow.ui` | Форма Qt Designer с меню, панелью инструментов, областью редактора и строкой состояния. |
| `src/ui/PlanView.h` | Класс `PlanView` на основе `QGraphicsView`. Перечисление `PlanTool` задаёт режим выделения, рисования здания, ограждения, дороги, цели или зоны монтажа. |
| `src/ui/PlanView.cpp` | Обрабатывает мышь, масштабирование, выделение и завершение контуров. Отображает объекты плана, выбранные камеры и покрытые или непокрытые цели. При ручном рисовании создаёт здание с одним внешним контуром. При отрисовке импортированных зданий оставляет открытые дворы незакрашенными. |
| `src/ui/PropertiesPanel.h` | Класс `PropertiesPanel` объявляет поля свойств выбранного объекта и сигнал подтверждения правки. |
| `src/ui/PropertiesPanel.cpp` | Показывает значения, разбирает ввод и передаёт изменения в `Project`. Выводит сообщение о причине отклонения. |
| `src/ui/LoginDialog.h` | Класс `LoginDialog` объявляет поля логина и пароля и хранит результат входа. |
| `src/ui/LoginDialog.cpp` | Вызывает `AuthService` и показывает результат проверки. |
| `src/ui/CatalogDialog.h` | Класс `CatalogDialog` объявляет таблицу каталога, форму модели и поля поиска и фильтрации. |
| `src/ui/CatalogDialog.cpp` | Вызывает операции каталога. Показывает исходный файл, запись по ID и отдельно открытый файл выборки. |

## Файлы и доступ

| Файл | Содержимое |
|---|---|
| `src/storage/ProjectFile.h` | Класс `ProjectFile` объявляет чтение и запись полного плана, включая географическую привязку и сохранённый результат. |
| `src/storage/ProjectFile.cpp` | Реализует двоичный формат с сигнатурой, версией, порядком байтов и ограничениями размеров. Сохраняет все части здания и внутренние контуры. Загружает и проверяет временный `Project`. Записывает файл с заменой после успешного сохранения. |
| `src/storage/CameraCatalog.h` | Класс `CameraCatalog` объявляет создание, чтение и поиск по ID, добавление, удаление и правку записей, сортировку, фильтрацию, запись и чтение выборки. `CatalogFilter` задаёт диапазоны параметров. `CatalogSortOrder` задаёт поле и направление сортировки. |
| `src/storage/CameraCatalog.cpp` | Реализует формат бинарной записи. При поиске и корректировке читает по одной записи без вспомогательного массива. При сортировке и выводе может использовать контейнеры. Операции чтения и изменения доступны после успешного входа. Формирование выборки записывает отдельный файл и сохраняет исходный каталог. |
| `src/auth/AuthService.h` | Класс `AuthService` объявляет первоначальную настройку одной локальной учётной записи и проверку логина и пароля. `UserSession` представляет подтверждённый вход. |
| `src/auth/AuthService.cpp` | Внутренняя структура `UserRecord` хранит логин и хэш пароля с параметрами и солью. `AuthService` читает учётные данные и проверяет пароль по сохранённому хэшу. В проекте предусмотрен Argon2id. Если руководитель укажет другой алгоритм, применяется его требование. |

## Видимость и подбор

| Файл | Содержимое |
|---|---|
| `src/geometry/VisibilityCalculator.h` | Класс `VisibilityCalculator` объявляет проверку видимости контрольной точки по положению камеры, её характеристикам и препятствиям из плана. |
| `src/geometry/VisibilityCalculator.cpp` | Проверяет дальность и оба угла обзора. Сравнивает высоту луча с высотой ограждений и зданий. Для зданий проверяет участки луча внутри каждой части здания за вычетом открытых дворов. Для района использует внутренний пространственный индекс препятствий. |
| `src/optimization/CandidateGenerator.h` | Класс `CandidateGenerator` строит контрольные точки и варианты установки. `CandidateOptions` задаёт шаги по стене и направлениям, а также предел числа вариантов. `CameraCandidate` хранит установку, цену через выбранную модель и индексы видимых контрольных точек. |
| `src/optimization/CandidateGenerator.cpp` | Разбивает линии наблюдения на контрольные точки, строит допустимые установки и вызывает расчёт видимости. Повторно использует проверку препятствий для той же пары позиции с высотой и цели. |
| `src/optimization/CameraOptimizer.h` | Класс `CameraOptimizer` принимает варианты и цели, возвращает `OptimizationResult`. `OptimizationOptions` хранит лимит времени и выбранный метод. |
| `src/optimization/CameraOptimizer.cpp` | Реализует жадное начальное решение и точный подбор. Отмечает доказанный минимум, найденную схему без доказанного минимума, доказанную невозможность покрытия, окончание времени без решения или отмену. |

## Импорт

| Файл | Содержимое |
|---|---|
| `src/import/GeoJsonReader.h` | Класс `GeoJsonReader` читает заранее скачанный файл GeoJSON с локального диска. `ImportedMap` хранит проверенные здания, дороги и географическую привязку для добавления в проект. |
| `src/import/GeoJsonReader.cpp` | Проверяет размеры и типы геометрии, преобразует географические координаты в метры и формирует `ImportedMap`. Приводит `Polygon` и `MultiPolygon` к одной модели здания и сохраняет внешние и внутренние контуры всех его частей. Для неизвестной высоты здания сохраняет признак, что её нужно уточнить перед расчётом видимости. |

## Связи модулей

- Редактор, бинарный файл и локальный импорт передают данные в одну модель `Project`. При импорте `GeoJsonReader` читает файл, `Project` проверяет объекты и принимает изменения, а `PlanView` показывает итоговый план.
- Подбор получает объекты плана и каталог камер. Генератор создаёт варианты и вычисляет видимость, оптимизатор выбирает комплект, интерфейс отображает результат.
- Поиск и корректировка каталога работают с основным бинарным файлом. У выборки есть собственный бинарный файл и отдельная команда открытия.
- Данные и алгоритмы используют метры и согласованное представление углов. Файлы хранят размеры чисел и порядок байтов в соответствии с форматом. Граница операции в интерфейсе обрабатывает ошибки чтения, записи, импорта и вычислений.
