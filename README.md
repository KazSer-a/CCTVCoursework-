# Структура проекта

Пути в таблице указаны относительно `CCTVcwg/`.

| Путь | Назначение |
|---|---|
| `CMakeLists.txt` | Сборка приложения и модульных тестов на Windows и Linux. Регистрация тестов в CTest. |
| `src/main.cpp` | Запуск приложения. |
| `src/ui/` | Окна Qt, редактор плана и отображение результатов. |
| `src/model/` | Объекты плана, цели наблюдения, места монтажа и модели камер. Проверка геометрии зданий и целей при добавлении в проект. |
| `src/storage/` | Бинарные файлы проекта, каталога камер и выборки. |
| `src/auth/` | Вход по локальной учётной записи и проверка пароля по хэшу. |
| `src/geometry/` | Расчёт видимости с учётом высот, углов обзора и препятствий. |
| `src/optimization/` | Варианты установки и подбор комплекта камер по стоимости. |
| `src/import/` | Импорт зданий и дорог из заранее скачанного файла GeoJSON. |
| `tests/` | Модульные тесты, включая проверку допустимых и ошибочных контуров зданий и линий наблюдения. |
